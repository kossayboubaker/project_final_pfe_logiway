───────────────────────────────────────────────────────────────────────────
POURQUOI CE PROBLÈME?
───────────────────────────────────────────────────────────────────────────

• Le modèle ML est sauvegardé en format pickle
• Pickle est sensible aux versions
• scikit-learn a changé de version (1.6.1 → 1.9.0)
• Le modèle doit être ré-entraîné avec la nouvelle version

C'est NORMAL après une mise à jour de Python ou scikit-learn
