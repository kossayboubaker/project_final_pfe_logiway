📌 MÉTHODE RAPIDE (LA PLUS SIMPLE):

1. Double-cliquer sur ce fichier:
   ➜ OUVRIR_RAPPORT_TESTS.bat

2. Le rapport s'ouvre automatiquement dans votre navigateur


📌 MÉTHODE MANUELLE:

1. Aller dans le dossier:
   ➜ backend\target\site\jacoco\

2. Double-cliquer sur:
   ➜ index.html

3. Le rapport s'ouvre dans Chrome/Edge/Firefox


📌 SI LE RAPPORT N'EXISTE PAS:

1. Ouvrir IntelliJ IDEA

2. Clic droit sur ReclamationServiceTest.java

3. Cliquer: "Run 'ReclamationServiceTest' with Coverage"

4. Attendre la fin des tests

5. Onglet "Coverage" → Clic droit → "Generate Coverage Report"

6. Choisir format HTML → OK

7. Relancer le fichier .bat
