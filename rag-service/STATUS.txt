INSTALLATION STEPS
───────────────────────────────────────────────────────────────────

1. Verify Prerequisites:
   - Python 3.10+ installed
   - XAMPP MySQL running (port 3306)
   - Ollama installed and running

2. Install Model:
   ollama pull qwen2.5:3b

3. Setup Service:
   cd rag-service
   setup.bat

4. Start Service:
   start.bat

5. Test Service:
   test_service.bat
   OR
   http://localhost:5003/docs
